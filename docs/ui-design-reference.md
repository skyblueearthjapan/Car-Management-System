# UI設計リファレンス（スクリーンショットより）

## 概要

本ドキュメントは、提供されたUIスクリーンショットから読み取った画面構成の詳細です。

---

## 画面レイアウト

### ヘッダー部分

```
┌─────────────────────────────────────────────────────────────────────────┐
│  LINE WORKS   [Web入力 / シート表示]     [1/23(金)][1/24(土)][1/25(日)]... │
│                                          [1/26(月)][1/27(火)][1/28(水)][1/29(木)] │
└─────────────────────────────────────────────────────────────────────────┘
```

#### 要素詳細
| 要素 | 説明 |
|------|------|
| LINE WORKS | システム名/ロゴ（左上） |
| Web入力 / シート表示 | モード切替ボタン |
| 日付タブ | 1週間分（1/23〜1/29）表示 |

### サブヘッダー

```
┌─────────────────────────────────────────────────────────────────────────┐
│  2026-01-23 (金)                          [✓保存済み] [◀前日][今日][翌日▶] │
└─────────────────────────────────────────────────────────────────────────┘
```

#### 要素詳細
| 要素 | 説明 |
|------|------|
| 日付表示 | 選択中の日付（例：2026-01-23 (金)） |
| 保存済み | 保存状態インジケーター（緑色） |
| 前日/今日/翌日 | 日付移動ボタン |

---

## メインコンテンツ

### 保有車両カード（owned）

6台の車両が横並びで表示される。

```
┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐
│          │  │          │  │          │  │          │  │          │  │          │
│ カローラ  │  │ 軽トラA   │  │ 軽トラB   │  │   ノア    │  │ハイエース │  │ハイエース │
│ ホワイト  │  │          │  │          │  │          │  │  8080    │  │  5050    │
│          │  │          │  │          │  │          │  │          │  │          │
│          │  │          │  │          │  │          │  │          │  │          │
└──────────┘  └──────────┘  └──────────┘  └──────────┘  └──────────┘  └──────────┘
```

#### カードスタイル
- 角丸の枠線（border-radius）
- 白背景
- 車両名は中央寄せ
- クリック可能（予約操作）

### 借用可能車両（borrowable）- 右下

```
                                                    ┌──────────┐  ┌──────────┐
                                                    │ カローラ  │  │   CX5    │
                                                    │ シルバー  │  │          │
                                                    └──────────┘  └──────────┘
```

#### 特徴
- 画面右下に配置
- メイン車両より小さめの表示
- 同じカードスタイルだが、区別された領域
